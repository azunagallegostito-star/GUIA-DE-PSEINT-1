1. Conceptos Básicos y Tipos de Datos

PSeInt es un entorno educativo que permite diseñar algoritmos mediante pseudocódigo en español antes de pasar a lenguajes formales. Un algoritmo es una secuencia ordenada y finita de pasos lógicos que transforman datos de entrada en resultados.

Paso clave 1 · Estructura base

Idea principal: Todo programa comienza con Algoritmo Nombre y cierra con FinAlgoritmo, organizando las instrucciones en orden secuencial.

Tipos de Datos Primitivos

Entero
Números sin decimales, positivos o negativos (ej. -4, 0, 25).
Real
Números con punto decimal para cálculos exactos (ej. 3.14, 16.5).
Caracter
Letras, símbolos o cadenas de texto entre comillas (ej. 'A', "Hola").
Logico
Valores booleanos de verdad: Verdadero o Falso.
Paso clave 2 · Entrada y salida de datos

Idea principal: Declara cada variable con Definir, muestra indicaciones claras con Escribir y captura datos del teclado con Leer.

2. Estructuras de Control y Buenas Prácticas

Clasificación de Estructuras

  • Secuenciales: Ejecución lineal paso a paso.
  • Condicionales: Si - Entonces - Sino y Segun - Hacer.
  • Repetitivas: Mientras, Repetir - Hasta Que y Para.
Paso clave 3 · Decisión lógica

Idea principal: En Si - Entonces - Sino, verifica siempre los límites de comparación (ej. >= 18) y cierra el bloque con FinSi.

Pasos para Resolver un Problema

  1. Identificar datos de entrada y salida esperada.
  2. Declarar variables con su tipo adecuado.
  3. Aplicar condiciones o ciclos según la lógica.
  4. Verificar los resultados con pruebas de escritorio.
Paso clave 4 · Ciclos iterativos

Idea principal: Asegúrate de que la variable de control avance en cada iteración de Mientras o Para para evitar bucles infinitos.

Paso clave 5 · Orden y buenas prácticas

Idea principal: Usa sangría (indentación) dentro de condicionales y bucles, y elige nombres descriptivos como promedio o total para detectar errores rápidamente.

3. Diagramas de Flujo

Paso clave 6 · Representación gráfica

Idea principal: Un diagrama de flujo conecta bloques geométricos mediante flechas desde Inicio hasta Fin, mostrando visualmente cada bifurcación.
